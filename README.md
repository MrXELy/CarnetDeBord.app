# CarnetDeBord.app

Application web locale pour noter et suivre mes trajets de chauffeur routier (France et Europe).

## Objectif

Enregistrer, pour chaque journée de travail :

- **Début de journée** : lieu, heure, kilométrage
- **Chargements** et **livraisons** : lieu, heure, kilométrage
- **Pleins de carburant** : lieu, heure, kilométrage, litres
- **Fin de journée** : lieu, heure, kilométrage

Toutes les données sont conservées et consultables à tout moment.
